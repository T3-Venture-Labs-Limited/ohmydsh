# Brand assets

| File | Use |
|---|---|
| `logo.svg`, `logo-512.png` | Mark: DeepSeek-blue circle with a negative-space whale |
| `mark.svg` | One-colour mark (`currentColor`) |
| `wordmark.svg` | "ohmydsh" set in Montserrat SemiBold, outlined (no font needed) |
| `lockup.svg`, `lockup-dark.svg`, `lockup.png` | Mark + wordmark, for light and dark backgrounds |
| `app-icon.svg`, `app-icon-1024.png` | App icon (desktop, Android) |
| `hero.svg`, `hero.png`, `social-preview.png` | README banner and link preview |

Colours: blue `#4D6BFE`, ink `#0A0A0A`, night `#0B0B0D`, paper `#F4F4F2`.
Type: Montserrat (the typeface DeepSeek's site uses for display), SemiBold for the name, always lowercase "ohmydsh". Montserrat is licensed under the SIL Open Font License 1.1, see `FONT-LICENSE-Montserrat.txt`.
