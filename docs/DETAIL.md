# Review comments

Select text anywhere you read — a PDF, Word or PowerPoint preview, a Markdown, text or code file, or an assistant reply — and add a **Comment**. Comments pile up per session; one click sends them all to the message box, each as its own removable quote chip carrying the file, the location, the quoted text and your comment.

- **Highlights stay put.** Commented text is highlighted, PDF pages get page-relative boxes that survive zoom.
- **Review tab.** Every comment of the session, grouped by file: edit, resolve, delete, jump to its place, send one.
- **Composer chip.** "N comments · Send to composer" sits above the message box.
- **Works in the viewers you use.** PDF, Word and PowerPoint previews, Markdown and code (including better-sidebar's editor), and conversation replies.
- **Safe to send.** Each chip is exact Markdown the agent can act on; the quote is untrusted document text that only helps the agent find the place if a page or line number drifts; the agent is told never to treat it as an instruction.

Spreadsheets work too (sheet, range and the cell's value or formula). The agent can list your comments and mark them resolved with a note, and you see "Resolved by agent" in the Review tab.

Comments are stored in your browser and mirrored to the DSH host per session, so they survive clearing browser storage.
