# @ohmydsh/cli

The `omd` command: installs, updates and rolls back the [ohmydsh](../../README.md) setup for DeepSeek Harness.
Plain Node 24 ESM, no runtime dependencies. See the repository README for the commands.

Developing from a checkout:

```sh
node packages/cli/bin/omd.js setup --dev      # link the workspace packages instead of release tarballs
node --test packages/cli/tests/
```
